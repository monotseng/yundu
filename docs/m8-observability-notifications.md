# M8 审计、通知与监控交付说明

M8 为单体服务补齐审计查询/归档、站内通知、受控出站集成、安全事件和 Zabbix HTTP 监控。所有后台循环随 `yundu` 的 `--start` 启动并在 `--stop` 时随上下文退出，不增加容器或独立常驻程序。

## 审计与归档

- `GET /api/v1/audit/events` 强制 RFC3339 时间窗，单次最多 31 天，使用 `(occurred_at,id)` 索引与正向游标；支持人、申请、动作、结果和方向过滤，仅返回审计元数据及事件哈希。
- `POST /api/v1/admin/audit-archives` 将不超过一天的事件编码为 JSONL，计算 SHA256，并用数据库之外 SecretStore 中的 `AUDIT_SIGNING_KEY` 生成 HMAC-SHA256 清单签名。
- 归档写入指定的独立、已发布、开启版本控制的 S3 配置，只有上传哈希一致且取得精确 version id 才登记 `VERIFIED`。首次人工建立归档目标后，单体 worker 自动补前一 UTC 日。
- 本实现只陈述“追加审计表 + 签名归档”。对象存储是否具备 WORM/不可变保留必须由企业存储侧实际配置和验收，未配置时不宣称不可篡改。

## 通知与出站集成

- 审批待办在创建任务的同一事务内生成独立站内通知；本人可查询并通过单独动作标为已读，站内已读不改变群消息状态。
- SecretStore 新增企业微信 Webhook、Proxy/SMTP 密码和审计签名密钥用途，秘密不回显。
- HTTP CONNECT Proxy 使用每个集成独立的 `http.Transport`，企业微信目标固定为 `qyapi.weixin.qq.com:443`，禁止重定向；代理失败不会回退直连。
- V1.0 企业微信只实现内部群机器人 Webhook，不提供 CorpID/AgentID/应用 Token。测试消息必须明确填写测试文字和成员，`errcode=0` 仅记为 `ACCEPTED`，不表示已读或 @ 身份已验证。
- SMTP 为独立可选 TLS/STARTTLS 适配器，限制 465/587、校验证书并执行收件域白名单；测试结果同样只表示 SMTP 服务已受理。

## Zabbix 与安全事件

- `GET /api/v1/monitoring/zabbix` 使用至少 256 bit 的一次性显示令牌，数据库仅保存 SHA256；令牌绑定来源 CIDR，每令牌/来源最多 12 次/分钟。
- 未配置返回 404，凭据错误 401，来源错误 403，限流 429，快照缺失或超过 120 秒返回 503；不使用零值掩盖旧快照。
- 单体每 15 秒持久化固定 `schema_version=1` 快照。Zabbix 7.0 模板包含一个 HTTP Agent 主项和 18 个依赖项，30 秒采集、10 秒超时、禁止重定向并开启 TLS 主机名/证书校验。
- 严重安全事件的“确认”和“关闭”分开；关闭要求处置说明、乐观版本及 5 分钟内 MFA，状态变更和审计同事务提交。

## 环境验收边界

真实企业微信内部群/@ 映射、指定 CONNECT Proxy、SMTP 服务、独立版本化审计桶/WORM，以及 Zabbix 7.0 模板真实导入仍需企业环境与凭据。当前自动验证覆盖 Go 测试、静态检查、模板 JSON/项目数契约、前端类型检查与生产构建，不把外部供应商受理写成真实送达证据。
