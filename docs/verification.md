## 已知依赖风险

`npm audit --omit=dev` 报告的告警主要来自 `@umijs/max` 的构建/开发依赖树，其中包含 1 个 critical、若干 high，部分上游暂未提供修复。生产二进制只嵌入静态构建产物，不携带 Node 服务运行时；但在正式发布前仍需升级或替换受影响的构建链并重新审计，不能将当前结果标记为供应链验收通过。
