| M2 | 组织/RBAC、可信入口、SecretStore、集成版本、双存储适配器 | 开发完成；双存储环境列入联调验收 |

## 当前外部待联调

- 真实手机 Microsoft Authenticator 扫码及双门户并发防重放。
- 企业 MySQL 8.4、两个独立对象存储、TLS/入口可信方向标识。
- 企业微信测试群、Webhook、人员映射及指定 HTTP CONNECT Proxy。
- Zabbix 7.0 模板真实导入、触发与恢复。
- 30 人 60 分钟、60 人 10 分钟预生产负载及故障恢复。

这些项目在得到真实环境与凭据前不会被标记为通过。

Docker/Compose、容器镜像及双实例高可用部署不进入当前启动链路，留到生产性能部署阶段结合实测资源再设计。
