# M7 本人领取与生命周期交付说明

M7 在目标网络门户向原申请人提供短时、单次启动的下载授权，由单体服务代理目标精确对象版本并维护实时撤销边界。

## 授权与流式下载

- 待领取列表只返回当前登录账号创建、处于当前目标入口、未过期且整单目标检查完整通过的文件。管理员角色不产生文件读取权。
- grant 签发事务复核请求乐观版本、本人、会话、入口、期限、整单文件状态和目标哈希，并立即占用 MySQL DOWNLOAD 槽位；全局槽满或单用户已有两个活动授权时返回 429。
- grant 默认 60 秒，仅能从签发时的用户、会话和目标入口启动一次。数据库保存 token 哈希；为幂等重放保留的 token 使用主密钥加密，不以明文进入通用 JSON 幂等记录。
- `/data/v1/downloads` 接受同源表单 POST，读取固定的目标 storage version、object key 和 version id。响应使用浏览器原生附件下载，不通过前端 `fetch → Blob` 缓存整文件。
- 下载使用 256 KiB 缓冲。活动流每 15 秒复核账号、session version、会话期限、请求期限/撤销状态和集成启用状态，同时以 90 秒租约续占槽位。
- `Range` 返回 416。本版不提供断点续传；可在申请有效期内重新申请新 grant 整文件领取。
- 只有后端完整发送预期字节且流式 SHA-256 等于目标冻结哈希，才记录 `COMPLETED`。连接中断和授权失效记录 `INTERRUPTED`，不宣称浏览器已经保存或打开文件。

## 状态、撤销与清理

- 首个文件完整发送后申请进入 `PARTIALLY_DELIVERED`；所有文件至少完整发送一次后进入 `DELIVERED`，但在有效期内仍可重复领取。
- 安全管理员可携带乐观版本、理由和 `Idempotency-Key` 撤销已发布申请。未启动 grant 立即释放槽位，在途流最迟于下一次 15 秒复核中止；fencing token 防止旧流释放后来者槽位。
- 维护 worker 每 30 秒处理未启动 grant、失联活动租约和到期请求。到期对象按来源/目标精确 version 创建持久删除任务；只有 S3 确认该版本不存在后才记录删除完成，技术失败有限退避重试。

真实双 S3/MinIO 的下载、删除权限、入口反向代理无缓冲和慢流撤销仍需企业环境联调；当前没有将这些外部结果标记为通过。
