# 云渡 v1.0.0-rc.5 发布说明

发布日期：2026-09-17

## 本次更新

- 将交付配置中的 `security.trust_portal_header_from` 默认值调整为 `0.0.0.0/0` 和 `::/0`，首次安装无需预先识别反向代理出口网段即可访问。
- 门户 Origin 校验继续生效；生产环境完成联调后，仍建议将该配置收紧为实际可信代理地址或 CIDR。
- 同步更新开发、生产和发行配置模板，以及部署和使用文档。
- 延续 v1.0.0-rc.4 的前端依赖安全升级与双架构单体交付能力。

## 发行介质

- `yundu-server-v1.0.0-rc.5-linux-amd64.tar.gz`
- `yundu-server-v1.0.0-rc.5-linux-arm64.tar.gz`
- `SHA256SUMS-v1.0.0-rc.5.txt`

每个架构包均包含对应静态二进制、生产配置模板、秘密环境变量模板、中英文 README、部署及运维文档、`PLATFORM` 平台信息和 `MANIFEST.sha256` 包内文件校验清单。

## 已知边界

本版本仍为发布候选版。前端构建链剩余 36 项上游告警（0 Critical），详情见 `frontend-dependency-audit.md`。允许全部来源声明门户域是为了降低首次安装门槛，并不替代门户 Origin 校验；面向不可信网络部署时应按部署文档收紧可信代理范围。
