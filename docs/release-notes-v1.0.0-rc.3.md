# 云渡 v1.0.0-rc.3 发布说明

发布日期：2026-09-17

## 交付范围

- Linux AMD64、ARM64 单体二进制发行包。
- 外部 MySQL 8.4、双安全域 S3/MinIO 配置。
- 组织与用户、角色权限、业务系统及团队管理。
- 双向文件申请、内容检查、审批编排、精确版本传输和本人领取。
- 集成配置、通知、审计、监控和安全恢复能力。
- 中文、英文界面切换及英文布局适配。
- 部署、使用、运行维护和数据库恢复文档。

## 升级提示

- 最新 schema version 为 `19`，启动前先备份并执行迁移。
- 语言切换入口统一显示目标语言 `zh`/`en`。
- 发行程序名为 `yundu-server`，支持 `--start`、`--status`、`--stop`。

## 发布性质

本版本为发布候选版，不是生产 GA。真实 Microsoft Authenticator、双版本化对象存储、ClamAV、企业微信、SMTP、WORM、Zabbix 7.0、30/60 人负载及旧备份恢复仍需在企业预生产环境留存验收证据。
